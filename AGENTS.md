1. If tasked with opening a PR or Issue, capture screenshots.
2. You may not comment on PRs or Issues.
3. Do not write release notes unless told so.
4. Do not write commits unless told so.
5. Do not write comments unless told so.
6. Do not prematurely write tests during development, write tests only when the user tells you to.
